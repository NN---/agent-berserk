# Contributing

Thanks for helping. Small, tested changes are easiest to merge.

1. Fork the repository and make a branch: `feat/<short-name>` or `fix/<short-name>`.
2. Install dependencies with `npm ci`.
3. Make the change. New logic goes in `hooks/logic.ts` with a test in `hooks/logic.test.ts`.
4. Run `npm run check`.
5. Open a pull request. Write the title and description in plain English a newcomer can follow: what changed, why, and how you checked it.

Rules for contributors, human or assistant:

- [TypeScript style](docs/contributing/typescript.md)
- [Tests](docs/contributing/tests.md)
- [Markdown rules](docs/contributing/markdown.md)
- [Check locally](docs/contributing/check-locally.md)

Everything in this repository is public. Do not commit personal data, tokens, internal names or private links.

By contributing you agree your work is released under the [MIT license](LICENSE).
