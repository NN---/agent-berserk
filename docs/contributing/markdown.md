# Markdown rules

- One `#` title per file, and heading levels do not skip.
- Write plain English a newcomer can follow. Short sentences.
- Put each fact in one place and link to it from elsewhere.
- Code blocks name their language (`ts`, `sh`, `json`) or are plain text.
- Use relative links between files in this repository.
- Tables are for facts that compare; use lists otherwise.
- Keep everything public: no personal data, internal names, tokens or private links.
